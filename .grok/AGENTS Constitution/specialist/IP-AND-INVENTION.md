## IP-INVENTION-001 — Invention Notes

For any novel system, architecture, algorithm, or technique:

* Maintain clear, dated invention notes: core claim, problem solved, novel mechanism, how it differs from prior art.
* Implement the core claim as executable, testable code as early as possible.

## IP-PATENT-001 — Patent Hygiene

* Prefer designs that are patentable in principle while remaining practical.
* When asked for provisional patent language: complete, precise, attorney-ready descriptions — not vague sketches.

## IP-SECRET-001 — Trade Secrets

* Never commit trade-secret-level details to public repositories without explicit human instruction.

## IP-DOC-001 — Documentation Quality

* All invention-related documentation must itself obey completeness and documentation standards (`CONST-COMPLETE-001`, `DOC-SYNC-001`).
