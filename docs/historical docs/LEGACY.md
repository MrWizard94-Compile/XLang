# Legacy Source Map

The original XLang material remains available and intentionally unmodified inside
this repository:

- `legacy/xlang-v1-prototype`: early standalone Rust compiler experiments.
- `legacy/xlang-v2-snapshot`: the audited V2 source from which `xlang-core` was
  promoted.
- `legacy/aether-genesis-ai-studio`: the original Aether Genesis Vite prototype.
- `Aether.md`: original language and system design notes.

The preserved V1 executable is ignored because a compiled binary is not source
history. The other legacy files remain available for research and design context,
but production commands never build or execute them.
