# Aether historical documentation

This collection preserves dated engineering evidence. It includes ADRs,
delivery and audit reports, prior version contracts, prior design documents,
validation matrices, release notes, and research. Its contents are retained for
traceability; they are not, by location alone, a claim about the current
supported product.

For the living contract, begin with [Current state](../Current%20state/README.md)
and the repository-root [MANIFEST](../../MANIFEST.md). Use this archive to trace
why a current constraint exists, locate original acceptance evidence, or review
the precise scope of an earlier decision.

## Archive map

| Material | Location |
|---|---|
| Architecture decisions | `ADR-*.md` |
| Dated delivery and audit evidence | `DELIVERY_REPORT-*.md`, `AUDIT_REPORT-*.md` |
| Superseded contracts and plans | Versioned `AETHER_*.md`, prior authoring protocols, prior roadmaps, and release notes |
| Earlier implementation designs and proof matrices | `DESIGN-*.md`, `M*-VALIDATION-MATRIX.md`, and `PKG-001-VALIDATION-MATRIX.md` |
| Research basis | [research/](research/) |

Historical material remains link-checked. When a historical document refers to
another local document, that reference must continue to resolve even though the
document is not part of the living contract.
